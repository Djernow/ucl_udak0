## 1. Common badge dimensions & reusable parts  

All badges are **64 × 64 px** (the same size Strava uses for its challenge icons).  
The outer “badge” shape is a rounded‑square with a 5 px corner radius.  
The icon itself is centered and sized to fit nicely inside the badge.

```svg
<!-- Template – replace {fill} with the tier colour,
     replace {icon‑path} with the specific icon path,
     replace {highlight‑path} with the same path shifted a bit for a white “glint”. -->
<svg width="64" height="64" viewBox="0 0 64 64"
     xmlns="http://www.w3.org/2000/svg">
  <!-- Badge background -->
  <rect x="1" y="1" width="62" height="62" rx="5" ry="5"
        fill="{fill}" stroke="#000" stroke-width="2"/>

  <!-- Icon (scaled to ~36 px height, centered) -->
  <g transform="translate(32,32) scale(0.5625) translate(-32,-32)">
    <!-- White highlight – a copy of the icon, slightly offset -->
    <path d="{icon-path}"
          fill="#fff" opacity="0.2"
          transform="translate(2,2)"/>
    <!-- Main icon -->
    <path d="{icon-path}" fill="#fff"/>
  </g>
</svg>
```

*Replace `{fill}` with one of the tier colours (see Table 1) and `{icon-path}` with the vector outline of the desired icon (the paths are provided below).*

## 5. Generating the remaining variants automatically (optional)

If you prefer not to manually copy‑paste 36 files, you can generate them with a tiny script (Python, Node, etc.) that:

1. Stores the six `iconPath` strings in a dictionary.  
2. Loops over `['bronze','silver','gold','black']`.  
3. Substitutes the appropriate background colour (or `#000` + no highlight for black).  
4. Writes the SVG string to `<icon>-<tier>.svg`.

### Example (Python)

```python
import os

icons = {
    "beer": "M20 12 h24 a2 2 0 0 1 2 2 v28 a2 2 0 0 1 -2 2 h-8 v4 a2 2 0 0 1 -4 0 v-4 h-12 a2 2 0 0 1 -2 -2 v-28 a2 2 0 0 1 2 -2 z M24 14 h4 v6 h-4 z M32 14 h4 v6 h-4 z M40 14 h4 v6 h-4 z",
    "duvel": "M26 8 h12 a1 1 0 0 1 1 1 v38 a1 1 0 0 1 -1 1 h-12 a1 1 0 0 1 -1 -1 v-38 a1 1 0 0 1 1 -1 z M30 20 h4 v14 h-4 z",
    "wine":  "M32 12 a10 10 0 0 1 0 20 h-4 a8 8 0 0 0 0 -16 h4 M28 32 v14 a2 2 0 0 0 4 0 v-14",
    "cocktail":"M20 12 l24 0 a2 2 0 0 1 0 4 h-24 a2 2 0 0 1 0 -4 M32 16 v20 a2 2 0 0 1 -4 0 v-20 M20 36 l24 0 a2 2 0 0 1 0 4 h-24 a2 2 0 0 1 0 -4",
    "shot":"M28 12 h8 a1 1 0 0 1 1 1 v28 a1 1 0 0 1 -1 1 h-8 a1 1 0 0 1 -1 -1 v-28 a1 1 0 0 1 1 -1 z M28 42 h8 v4 a1 1 0 0 1 -1 1 h-6 a1 1 0 0 1 -1 -1 v-4",
    "joint":"M24 12 h16 a2 2 0 0 1 2 2 v24 a2 2 0 0 1 -2 2 h-4 v8 a2 2 0 0 1 -4 0 v-8 h-8 a2 2 0 0 1 -2 -2 v-24 a2 2 0 0 1 2 -2 z M28 28 h8 a1 1 0 0 1 0 2 h-8 a1 1 0 0 1 0 -2 z"
}

colors = {
    "bronze": "#CD7F32",
    "silver": "#C0C0C0",
    "gold"  : "#FFD700",
    "black" : "#000000"
}

template = """<svg width="64" height="64" viewBox="0 0 64 64"
     xmlns="http://www.w3.org/2000/svg">
  <rect x="1" y="1" width="62" height="62" rx="5" ry="5"
        fill="{bg}" stroke="#000" stroke-width="2"/>
  <g transform="translate(32,32) scale(0.5625) translate(-32,-32)">
{highlight}
    <path d="{path}" fill="{fill}"/>
  </g>
</svg>"""

for icon, path in icons.items():
    for tier, bg in colors.items():
        highlight = ""
        fill = "#fff"
        if tier != "black":
            highlight = f'    <path d="{path}" fill="#fff" opacity="0.2" transform="translate(2,2)"/>\n'
        else:
            fill = "#000"
        svg = template.format(bg=bg, highlight=highlight, path=path, fill=fill)
        filename = f"{icon}-{tier}.svg"
        with open(filename, "w") as f:
            f.write(svg)
```

Running the script will generate **all 36 SVG files** in the current directory.
